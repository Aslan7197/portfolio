Key idea
의존 관계 분석으로 상호 의존 버그 청크를 하나의 "버기 블록"으로 묶고, 통합 표현으로 CodeBERT를 파인튜닝합니다.
MRL
최소화된 수정 위치 — FAULT_OF_OMISSION 태그가 없는 한 공백/주석/널 라인을 제외하여 패치 검색 노이즈를 줄입니다.
Patch optimization
(1) 필터: 중복, 문법 오류, 관련 없는 패치 제거  (2) 순위: 합집합 분모로 적은 편집 동작에 보상  (3) 결합: 위치별 비례 top-k
Bug taxonomy
T1 단일 청크 · T2 단일 청크 다중 위치 · T3 다중 청크 — 시스템은 가장 어려운 T3에 집중합니다.
Projects

Classification
FULL_LOCATION — 직접 AST 인덱스 조회, LLM 없음 (~$0.01) · PARTIAL — 심볼 요약에 대해 1회 LLM 추론 호출 (~$0.04) · HINT — 최대 5회 반복 에이전트 탐색 (~$0.05)
Repo indexing
Python ast 모듈로 파일별 전체 심볼 인덱스 구축(함수, 클래스 요소, 모듈 심볼); basename/suffix/module path 3중 파일 해결기 — 임베딩 불필요
PARTIAL handler
심볼 요약(80줄 발췌 + 추론 호출 그래프) 작성 → GPT-4o가 EDIT_LOCATION / SYMPTOM_ONLY / NOT_RELATED로 분류
HINT handler
에이전트가 메모리 AST 인덱스를 기반으로 search_class / search_method / search_code를 반복 호출; 발견 순서에 따라 점수가 감소(빠를수록 가중치 높음)
Budget
이슈당 $0.50, 3,000초 하드 제한; 한도 근접 시 선택적 LLM 단계를 비활성화하여 안정적으로 감쇠
